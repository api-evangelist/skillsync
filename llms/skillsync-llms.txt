# Skillsync

> Skillsync gives your AI coding sessions a permanent home — "GitHub for your agent sessions." Install the `skl` CLI, sign in once, and publish a session; revisit past work, share the full context behind a change, and turn workflows that worked into reusable skills. The CLI finds sessions from Claude Code (full support), Codex and OpenCode (beta), and also pi, Campfire, Cursor, Grok, Amp, and Antigravity. Skillsync is a Y Combinator (W2026) company. No public REST API — the CLI and its bundled Model Context Protocol server are the integration surface.

## Tooling
- [skl CLI (GitHub Releases)](https://github.com/skillsynchq/skl-releases/releases): First-party binary; install via `curl -fsSL https://install.skillsync.com | sh`.
- [MCP server](https://skillsync.com/docs/mcp-server): `skl mcp` over stdio — list_sessions, search_sessions, get_session, search_replay, get_replay_thread, upload_session, list_workspaces, list_skills, get_skill, install_skill, upload_skill, auth_status.
